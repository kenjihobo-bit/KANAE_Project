# team-review 統合レポート:副業やるなら何がおすすめ?

KANAEの仕組みを、2つ目の公開デモお題で動かした結果です。**特定の個人の副業状況・実データは使わず、
一般的な相談として実行しています。** 全ラウンドの生ログは
[side-hustle-recommendation_team-review-log.md](side-hustle-recommendation_team-review-log.md)を参照。

## 1. お題

副業やるなら何がおすすめ?(個人の実データを含まない、一般的なお題)

## 2. 役割分担とその理由

GPTが「プロデューサー担当」、Geminiが「リサーチ担当」を希望し、希望が割れずそのまま噛み合った
(パターンB採用)。1つ目のデモ(examples/demo-review/)では両者とも「プロデューサー担当」を志願して
重複したが、今回は重複しなかった。**「両者とも同じ役割を志願する」現象は毎回起きるわけではなく、
お題によって変わる**ことが確認できた。

## 3. 各ラウンドのやり取り(要約)

**ラウンド1(率直な意見)**
- GPT(プロデュース担当):副業を①本業スキル販売・業務受託、②講師・コンサル・コンテンツ販売、
  ③せどり・EC・ハンドメイド、④SNS・YouTube・ブログ発信、の4タイプに整理。あまりおすすめしないもの
  (高額情報商材・不透明な投資コミュニティ等)も列挙し、タイプ別の結論と、会社の副業規定・確定申告等の
  注意点を提示。
- Gemini(リサーチ担当):①本業スキルのコンサル・業務委託(★5)、②動画編集・Webライティング等の
  デジタルワーク(★4)、③資産型コンテンツビジネス(★2、人を選ぶ)の3タイプに整理し、それぞれの
  おすすめ度・注意点を提示。ポイ活・データ入力・せどり・投資系副業は非推奨とし、「蓄積性(スキルや
  実績が積み上がるか)」で選ぶべきと結論。

**ラウンド2(弱点の指摘)**
- GPT→Geminiへ:個人の前提条件(時間・資金・営業力・副業許可の有無等)を無視した万人向けの順序に
  なっている/本業スキル販売の初回受注難易度を軽く見ている/動画編集・Webライティングの再現性は
  条件付き/AIの影響を単純作業減少としか捉えていない/集客コストと営業力の影響を扱っていない/法務税務面の
  注意が不足/投資を一括りに否定しすぎ/資産型コンテンツを「放置収益」と誤解させる表現/選択肢が狭い/
  収入の緊急性とのトレードオフがない、の10点を指摘。
- Gemini→GPTへ:生成AIの台頭で初心者向けスキル販売(Webライティング・資料作成等)は単価下落・
  レッドオーシャン化している/本業経験が市場価値に変換できるとは限らない過度な楽観/業務受託の
  クライアント対応による精神的・時間的コストの軽視/SNS集客・コンテンツ販売に必要なマーケティング
  スキルの壁の過小評価/低単価クラウドソーシングの一律否定による初心者の成功体験機会の損失、の5点を
  指摘。

**ラウンド3(統合案)**
- GPT:自分の「4タイプ整理」を活かしつつ、「万人向けのおすすめ順」から「条件別の選び方」に組み替え。
  ①本業スキル販売型、②知識・経験の販売型、③物販・EC型、④発信・コンテンツ型、+⑤単発・代行型に
  再整理し、「早く収入が必要」「専門性がある」「営業が苦手」「資金がある」「長期で育てたい」の
  条件別におすすめを分岐させる案を提示。
- Gemini:自分の「蓄積性重視」の軸に、相手の「市場の現実・実行可能性」の視点を組み込んだ
  「フェーズ別成長ロードマップ」案(Step0:実績ゼロ体験→Step1:本業スキルのニッチ化&クライアントワーク→
  Step2:生成AI活用型デジタルワーク→Step3:資産型コンテンツ・事業化)を提示。

## 4. 最終的な統合判断・結論

**採用度88%。** ラウンド3の時点で、GPT案(条件分岐型)とGemini案(フェーズ型ロードマップ)は
「唯一の正解を示さず、個人の状況・時間軸に応じて設計する」という方向性で完全に一致した。両者は
「軸の違う地図」であり、対立ではなく補完関係にあると判断する。

進行役としての最終統合案は以下の通り:

1. **まず自分の制約条件を整理する**(使える時間、初期資金、副業の緊急性、本業の副業規定、営業への
   抵抗感)。GPT案の「条件別分岐」がここで効く。
2. **時間軸で段階を分ける**(Gemini案の4フェーズ):
   - **Step0(最初の数週間)**:不用品販売・単発案件など、低リスクで「自力で稼ぐ感覚」を掴む
   - **Step1(数ヶ月)**:本業スキルを「そのまま」ではなく「ニッチな一部工程」に絞って商品化する
   - **Step2**:生成AIを競合ではなく生産性向上ツールとして使い、専門性とAI活用を組み合わせる
   - **Step3**:実務で得た知見をもとに、発信・コンテンツなど資産型の収入源へ拡張する
3. **「動画編集」「Webライティング」等は「始めやすい」ことと「安定して稼げる」ことは別**、という
   両者共通の指摘は、そのまま読者への注意喚起として重要。
4. **投資は副業と分けて、資産形成の選択肢として整理する**(GPTの指摘採用)。
5. **法務・税務(副業規定・競業避止・確定申告・インボイス等)の確認は、収入が増えてからではなく
   最初から行う**、という両者共通の結論を採用。

## 5. note記事の実演パートに使えそうなポイントのメモ

- **役割分担の重複が「毎回起きるわけではない」ことを、1本目(部屋の片付け)との対比で示せる。**
  1本目は両者ともプロデューサー担当を志願、2本目は自然に分かれた。「毎回同じ展開になるわけではなく、
  お題によって変わる」という再現性のなさ自体が、実際に動かしている証拠として説得力を持つ。
- ラウンド1の時点でも、GPTは「タイプ別の実行プラン」、Geminiは「星評価付きの市場分析」と、
  すでに口調・視点の違いが出ている。プロデュース担当/リサーチ担当という役割名の意味が、内容にも
  ちゃんと表れている実例として使える。
- ラウンド2の指摘の応酬(「初心者向けスキル販売はAIでレッドオーシャン化している」
  「低単価クラウドソーシングを否定すると初心者の成功体験の機会を奪う」など)は、副業に関心がある
  読者にとってそのまま実用的な気づきになっている。1人に相談しただけでは出てこない視点。
