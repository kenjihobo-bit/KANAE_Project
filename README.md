# KANAE

Claude Codeを「進行役」、GPT・Geminiを「論者」にして、1つのお題を実際に3ラウンド議論させ、最終的に
進行役が統合判断する仕組み一式です。ノウハウやプロンプトの断片ではなく、**普段そのまま使っている
コード・手順を、包み隠さずそのまま公開**しています。

## これは何か / 何ではないか

- これは、コピペだけで誰でもすぐ試せる「体験版」ではありません。Node.jsのセットアップ、GPT・Geminiの
  APIキー取得、Claude Code(または同等の環境)が必要です。
- その代わり、実際に動いているものをそのまま渡します。省略も簡略化もしていません。
- 「1つのAIが役割を切り替えて自問自答する」簡易版ではなく、**実際に別のモデル(GPT・Gemini)同士が
  議論する**、本来の仕組みです。同じモデル同士だと学習データ・傾向が似ているため、意見の多様性や
  誤り訂正効果が下がります。ここでは、進行役(Claude)と論者(GPT・Gemini)がすべて別モデルであることを
  重視しています。

セットアップ・課金の手間はそれなりにあります。それでも、実際にAI同士が議論して意見が磨かれていく
過程を自分の手元で動かしてみる価値はある、という考えで公開しています。

## 必要なもの・費用の目安

| 項目 | 必要なもの | 費用の目安 |
|---|---|---|
| 進行役 | Claude Code(有料プラン) | Proプランで$17〜20/月(2026年8月時点。無料プランではClaude Codeは使えません) |
| 論者1 | OpenAI APIキー | 数百円〜(このプロジェクトでは月5ドルをチャージして運用) |
| 論者2 | Gemini APIキー | 月2,000円程度(お題の量による) |
| 実行環境 | Node.js | 無料 |

**議論1テーマ(役割分担+3ラウンド+統合)あたり、GPT・Geminiそれぞれ4回ずつ、計8回のAPI呼び出しが
発生します。** 費用はお題の長さ・回答の長さによって変わるので、まずは少額のチャージから試すことを
おすすめします。

## セットアップ

プログラミング未経験の方は、先に[docs/getting-started.md](docs/getting-started.md)(はじめての方向けセットアップガイド)を読むことをおすすめします。ここでは要約版の手順のみ記載します。

1. Node.jsをインストールする(未導入の場合)。
2. このリポジトリを取得し、直下で依存パッケージをインストールする。

   ```bash
   npm install
   ```

3. `.env.example` を `.env` にコピーし、取得したAPIキーを記入する。

   ```bash
   cp .env.example .env
   ```

   ```
   OPENAI_API_KEY=sk-...
   GEMINI_API_KEY=...
   ```

   `.env` はGitにコミットされません(`.gitignore`で除外済み)。

4. 動作確認として、それぞれのスクリプトを単体で試す。

   ```bash
   node scripts/ask-gpt.js "こんにちは"
   node scripts/ask-gemini.js "こんにちは"
   ```

   どちらも応答が返ってくれば準備完了です。

## 使い方

1. Claude Code(または同等の、ファイル操作・コマンド実行ができるAIコーディング環境)で、このリポジトリを
   開く。
2. [docs/team-review-procedure.md](docs/team-review-procedure.md) の内容を会話で渡し、「この手順で、
   お題は〇〇について実行して」のように指示する。
3. 進行役が、役割分担会議→3ラウンド議論→統合レポート作成、までを自動で行う。

実際にこの手順を動かした例(役割分担が割れて進行役が裁定するところ・3ラウンドの応酬・最終的な統合判断
まで、すべて改変なしの生ログ)を[examples/demo-review/](examples/demo-review/)に置いています。まずは
これを読むと、何が出てくるかが一番早くわかります。

## 制約・注意点

- `scripts/sleep-guard.ps1` はWindows専用(PowerShell + `powercfg`に依存)です。他のOSでは省略しても
  仕組み自体は動きます。
- カスタムスラッシュコマンド(`/team-review`のような形)として登録できるかは、使っているClaude Code
  環境によって挙動が異なります。認識されない場合は、手順書の内容を会話で直接渡す方法を使ってください。
- GPT・Gemini双方のモデル名(`gpt-5.6-terra` / `gemini-3.6-flash`)は、それぞれ環境変数
  `OPENAI_MODEL` / `GEMINI_MODEL` で上書きできます。
