# はじめての方向けセットアップガイド

プログラミング未経験の方でも、この手順通りに進めれば動かせるように書いています。
[README](../README.md)の要約版ではなく、README よりも一段階詳しく、つまずきやすい箇所を補った版です。

## 全体の流れ

1. 必要なものを揃える(お金と時間の目安を先に把握する)
2. Node.js をインストールする
3. このリポジトリを手元に持ってくる
4. 依存パッケージをインストールする
5. OpenAI・Gemini の API キーを取得する
6. `.env` にキーを設定する
7. 動作確認する
8. Claude Code(または同等の環境)で実際に動かす

---

## 1. 必要なもの

| 項目 | 説明 | 費用の目安 |
|---|---|---|
| パソコン | Windows または Mac。スマートフォンだけでは動かせません | - |
| Node.js | JavaScriptを動かすための実行環境 | 無料 |
| OpenAI APIキー | GPTを呼び出すために必要 | 数百円〜(月5ドル程度から試すのがおすすめ) |
| Gemini APIキー | Geminiを呼び出すために必要 | 無料枠あり、使用量次第で課金 |
| Claude Code(または同等の環境) | ファイル操作・コマンド実行ができるAIコーディング環境 | Proプランで$17〜20/月(2026年8月時点)。無料の「Claude」アプリ・Webチャットではファイル操作やコマンド実行ができないため、この仕組みは動かせません |

**課金が不安な方へ**:OpenAI・Geminiともに、いきなり高額請求が来る心配は基本的にありません。OpenAIは事前にチャージした金額の範囲でしか使えず、Geminiも無料枠があります。まずは少額(OpenAIなら5ドル程度)から試すことをおすすめします。

**「Claude」の無料チャットではダメなの?と思った方へ**:はい、無料の「Claude」アプリ・Webチャット(claude.ai)だけでは、このKANAEは動かせません。KANAEは、お使いのパソコン上でNode.jsのスクリプトを実際に実行し、ファイルを読み書きしながらGPT・Geminiに議論させる仕組みだからです。claude.aiのチャット画面は会話するだけの機能で、パソコンのファイル操作やコマンド実行の権限を持っていません。この権限を持つ「Claude Code」というツールが、Proプラン以上(無料プランでは不可)で使えるようになります。

## 2. Node.js のインストール

1. [https://nodejs.org/](https://nodejs.org/) にアクセスする
2. 「LTS」と書かれている方(推奨版)をダウンロードする
3. ダウンロードしたインストーラーを実行し、画面の指示に従って進める(基本は「次へ」を押すだけでOK)
4. インストールが終わったら、確認する。ターミナル(Windowsなら「PowerShell」、Macなら「ターミナル」)を開き、以下を入力してEnter

   ```bash
   node -v
   ```

   `v20.11.0` のようにバージョン番号が表示されれば成功です。「認識されていません」のようなエラーが出る場合は、一度パソコンを再起動してから再度試してください。

## 3. リポジトリを手元に持ってくる

2つの方法があります。どちらでも構いません。

**方法A: git を使える場合**

```bash
git clone https://github.com/kenjihobo-bit/KANAE_Project.git
cd KANAE_Project
```

**方法B: git を使ったことがない場合**

1. [GitHubのリポジトリページ](https://github.com/kenjihobo-bit/KANAE_Project)を開く
2. 緑色の「Code」ボタン → 「Download ZIP」
3. ダウンロードしたZIPファイルを、わかりやすい場所(デスクトップなど)に展開(解凍)する
4. ターミナルで、展開したフォルダに移動する(例:`cd Desktop\KANAE_Project-main`)

---

## 4. 依存パッケージのインストール

リポジトリのフォルダ内で、以下を実行します。

```bash
npm install
```

数十秒〜数分かかります。エラーが出ずに終われば成功です。

---

## 5. APIキーの取得

### OpenAI(GPT)のキー

1. [https://platform.openai.com/](https://platform.openai.com/) でアカウントを作成する
2. 左メニューの「Billing(お支払い)」から、支払い方法を登録し、少額(5ドル程度)をチャージする
3. 左メニューの「API keys」から「Create new secret key」を選び、新しいキーを発行する
4. `sk-` から始まる文字列が表示されるので、コピーしてどこかにメモしておく(**この画面を閉じると二度と表示されません**)

### Gemini のキー

1. [https://aistudio.google.com/](https://aistudio.google.com/)(Google AI Studio)に、お使いのGoogleアカウントでログインする
2. 「Get API key」から新しいキーを発行する
3. 表示された文字列をコピーしてメモしておく

---

## 6. `.env` にキーを設定する

リポジトリのフォルダ内で、テンプレートファイルをコピーします。

```bash
cp .env.example .env
```

作成された `.env` ファイルを、メモ帳などのテキストエディタで開き、先ほど取得した2つのキーを貼り付けます。

```
OPENAI_API_KEY=sk-ここに取得したキーを貼り付け
GEMINI_API_KEY=ここに取得したキーを貼り付け
```

保存して閉じます。

⚠️ **注意**:この `.env` ファイルは、あなた専用の"鍵"です。他人に見せたり、SNSやブログのスクリーンショットに映り込ませたり、GitHubにアップロードしたりしないでください。このリポジトリの設定(`.gitignore`)では自動的に除外されるようになっていますが、コピーの取り扱いには注意してください。

---

## 7. 動作確認

以下を1つずつ実行してみてください。

```bash
node scripts/ask-gpt.js "こんにちは"
node scripts/ask-gemini.js "こんにちは"
```

それぞれ、AIからの返答がターミナルに表示されれば準備完了です。

**うまくいかないときのチェックリスト**

| 症状 | 確認すること |
|---|---|
| `command not found` / `認識されていません` | `npm install` を実行し忘れていないか |
| 401エラー・認証エラー | `.env` のキーが正しくコピーされているか(前後に余計なスペースや改行が入っていないか) |
| OpenAI側だけエラーになる | Billingでの支払い方法登録・チャージが済んでいるか |
| Gemini側だけエラーになる | キーが正しいAI Studioプロジェクトのものか(複数プロジェクトを作っている場合、キーの紐付け先を確認) |

## 8. Claude Code で実際に動かす

1. Claude Code(または、ファイル操作・コマンド実行ができる同等のAIコーディング環境)で、このフォルダを開く
2. [docs/team-review-procedure.md](team-review-procedure.md) の内容を会話でそのまま渡す
3. 「この手順で、お題は〇〇について実行して」のように指示する
4. 役割分担会議 → 3ラウンド議論 → 統合レポート作成、までが自動で進みます

実際に動かした例([examples/demo-review/](../examples/demo-review/)、[examples/side-hustle-recommendation/](../examples/side-hustle-recommendation/))を先に読んでおくと、何が出てくるかイメージが掴みやすいです。
